Meja Foto Kaone.

Salin, pindahkan, dan ubah nama foto langsung dari folder di komputer Anda — semua diproses lokal di peramban, tidak diunggah ke mana pun.

Peramban ini tidak mendukung akses folder langsung (File System Access API). Buka file ini dengan Google Chrome atau Microsoft Edge versi desktop terbaru agar semua fitur berfungsi.

Folder Sumber

Belum ada folder ditambahkan. Klik "Tambah Folder" lalu pilih folder berisi foto. Bisa tambah lebih dari satu folder — centang folder mana saja yang mau ditampilkan di grid.

Foto dari Tautan

Foto dari tautan hanya bisa dilihat, dipratinjau, dan dipilih namanya — tidak bisa disalin, dipindah, atau diubah nama karena bukan berkas lokal di komputer Anda.

Pilih dari Teks Salinan

Tempel daftar nama file (dipisah baris baru atau koma) untuk otomatis memilihnya di grid — berguna untuk memindah/menyalin banyak foto sekaligus berdasarkan daftar.
